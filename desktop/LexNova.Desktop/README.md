# Lex Nova Desktop

نسخهٔ دسکتاپ آفلاین Lex Nova برای ویندوز است. رابط و داده‌های کاری در خود برنامه نگهداری می‌شوند؛ اجرای روزمره نیازی به راه‌اندازی وب‌سرور یا باز کردن مرورگر ندارد.

1. در ریشهٔ پروژه، `npm run desktop:prepare` را اجرا کنید تا فایل‌های محلی رابط آماده شوند.
2. فایل `LexNova.sln` را در Visual Studio باز کنید و پروژه را Publish کنید.
3. فایل `LexNova.Desktop.exe` در پوشهٔ انتشار را اجرا کنید؛ پوشهٔ `Web` کنار آن باید باقی بماند.

برنامه از WebView2 به‌عنوان موتور نمایش داخلی استفاده می‌کند و هیچ مرورگر خارجی باز نمی‌شود. داده‌ها روی همان دستگاه ذخیره می‌شوند و از بخش تنظیمات قابل پشتیبان‌گیری و بازیابی‌اند. قابلیت‌های هوش مصنوعی یا اتصال به سرویس‌های بیرونی، در حالت آفلاین در دسترس نیستند.
